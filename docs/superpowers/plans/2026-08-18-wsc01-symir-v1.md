# WSC-0/WSC-1 Wolfram Capability Seal and Neutral SymIR v1 Implementation Plan

**Goal:** Seal the Wolfram 15 capabilities used by BASS and establish the first language-neutral Continuum SymIR contract.

**Architecture:** Wolfram/xAct remains mathematical authority, the neutral SymIR is the reproducible compiler boundary, Python/SymPy owns structural passes/lowering, and Rust remains the production runtime. Continuum IR is strictly separated from future discretization IR.

**Tech Stack:** Wolfram Engine 15.0.1, Python 3, dataclasses, JSON, pytest.

## Global constraints

- Wolfram C codegen is disabled unless separately approved.
- Private `NDSolve`` internal APIs cannot be compiler contracts.
- Pointwise angular rates cannot be silently scalarized.
- Only exact identities/invariant predicates may rewrite authority equations.
- Continuum IR cannot contain discretization metadata.
- Production migration remains blocked.
