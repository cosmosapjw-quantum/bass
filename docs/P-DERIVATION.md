## D1 · 평행이동 법칙 — 회전계수에서 직접

정규직교틀의 교환함수:
```
[e_0, e_a] = −(H δ_a^b + σ_a^b + ε_a^{bc}R_c) e_b ,   C^0_{ab} = C^0_{0a} = 0
[e_a, e_b] = (ε_abd n^{dc} + a_a δ^c_b − a_b δ^c_a) e_c
```
Ricci 회전계수는 **기억해서 쓰지 않고** 두 조건에서 풀었다:
```
(계량 적합)  Γ_abc = −Γ_bac
(무비틀림)   Γ_abc − Γ_acb = −C_abc
⇒  Γ_abc = ½(−C_abc − C_bca + C_cab)            … 유일해
평행이동:    dV^a/dλ = −Γ^a_bc V^b P^c ,  P = (E, p^a)
```

### ★★ 반증 기록 (이 유도의 핵심)
처음엔 두 가지를 틀렸다.

1. **후보 법칙**: "T1 의 이차항에서 p_c → V_c 로 바꾸면 된다".
   기각: d(V·p)/dt ≠ 0, 좌표 대조 **3.2e−1**.
   원인 — 4-벡터의 **시간성분 V_0 가 수송으로 생성**된다. 널 조건이 V_0 를 묶어주는
   운동량과 달리 일반 벡터는 그렇지 않다.
2. **Koszul 식**: 기억한 ½(C_abc + C_cab − C_bca) 를 썼다. 이 식은 (a,b) 에
   **대칭**이라 계량 적합성을 위반한다. 그런데 C_abc 가 (b,c) 에 반대칭이라
   **측지선 방정식에서 통째로 빠진다** — 그래서 운동량 대조는 2.1e−14 로 통과하고
   편광만 틀렸다.
   ⇒ **"운동량이 맞으니 접속이 맞다"는 추론이 성립하지 않는다.**
   이제 `rotation_coefficients` 가 Γ_(ab)c = 0 을 자기검사한다.

### 게이트 (실측)
| 대조 | type V | type II |
|---|---|---|
| 좌표 측지선 vs 회전계수 (운동량) | 2.14e−14 | 1.20e−14 |
| 좌표 평행이동 vs 회전계수 (편광) | **2.15e−14** | **1.45e−14** |

## D2 · 직교성

V·p 는 평행이동의 계량 보존으로 자동 보존. 실측 표류 **5.3e−14** (type V),
4.8e−14 (type II).
스크린 대표원: `W_a = V_a − (V_0/E) p_a`  (W_0 = 0, W·p = 0) — 캐리어가 들 물리량.

## D3 ★★ 스크린 홀로노미 = **순수 회전** (계획 §1.2 예측의 증명)

두 독립 편광 벡터를 날라 초기·최종 스크린 정규직교기저 사이의 2×2 사상을 SVD:

| | leak (스크린 이탈) | aniso (σ_max/σ_min − 1) | scale | ψ |
|---|---|---|---|---|
| type V | 3.41e−15 | 3.55e−15 | **1.000000** | +0.148541 |
| type II | 2.17e−15 | 8.88e−16 | **1.000000** | −1.967033 |

⇒ 예측보다 **강한 결과**: 배율이 1 이다. 즉
```
편광 수송  =  (세기와 동일한 스칼라 수송)  ⊗  (스크린 SO(2) 회전 ψ)
```
그리고 스크린 제약은 수송으로 **기계정밀 보존**된다 (leak 3e−15).

**비용 귀결**: 편광 확장은 텐서 수송이 아니라 **노드당 각 하나 (ψ)** 다.
ψ 는 특성곡선을 따라 적분되는 스칼라 율이므로, 기존 `dln p` 옆에 성분 하나 추가.

## D5 ★★ 편광 Thomson 은 **정확히 rank-9**

기저-없는 형식 (Stokes 부호 규약 불필요):
```
(K J)_ab(ê') = (3/8π) ∫ dΩ  Π_ac(ê') J_cd(ê) Π_db(ê') ,   Π = δ − êê
```
투영자가 **ê′ 에만** 의존하므로 ê 적분은 상수텐서 하나로 축약된다:
```
M_cd = ∫ J_cd(ê) dΩ      (9 성분)   ⇒   K 는 rank 9.  l-분해가 필요 없다.
```
반복 적용은 M 위의 선형사상이 되고, 구면 항등 ∫n̂n̂ = (4π/3)δ,
∫n̂n̂n̂n̂ = (4π/15)(δδ+δδ+δδ) 로 닫힌형이 나온다:
```
𝒦[M] = (7/10) M + (1/10) tr(M) δ      (대칭부)
𝒦[A] = (1/2) A                        (반대칭부 = V)
고유값:  1 (트레이스, 광자 수 보존) · 7/10 (무대각 대칭 5차원) · 1/2 (V, 3차원)
```
⇒ **정확 지수가 다시 3항**으로 (스칼라 (★) 의 완전한 유비):
```
exp(x C) J = e^{−x} J
           + (3/8π) Π(ê′) [ Σ_λ ((e^{−x(1−λ)} − e^{−x})/λ) P_λ M ] Π(ê′)
```
비용 O(n_ang) + 9-성분 축약. **Sinkhorn·행렬지수·l 분해 전부 불필요**,
강성 소멸·근사 절환 부재가 편광에서도 유지된다.

### 게이트 (실측)
| 항목 | 값 |
|---|---|
| 𝒦 닫힌형 vs 구적 | 1.998e−15 |
| 고유값 (재계산, 하드코딩 아님) | 정확히 (1, 0.7, 0.5) |
| **3항 vs Taylor 심판** (x = 0.01…50) | ≤ **1.60e−14** |
| 강성 x = 10⁶ | 유한, x = 10⁷ 과 차 0.0 |
| 광자 수 보존 | 4.34e−15 |
| V 생성 안 됨 (대칭 입력 → 반대칭 출력) | 5.55e−17 |
| **비등방 무편광 → 편광 생성** | 2.12e−2 |
| **등방 무편광 → 편광 생성** | 8.33e−16 (정확히 0) |

마지막 두 줄이 물리 서명이다: 편광은 **사원극에서만** 생긴다.

## D6 · 미해결로 남긴 것 (정직하게)

**무편광 축약의 정체**: 편광 연산자의 트레이스를 스칼라 3항과 비교하면
- 매끄러운 입력: **4.4e−16** (x ≤ 0.3) — 정확히 일치
- 난수 (앨리어싱 많은) 입력: 7e−5 … 1.9e−3

⇒ 차이는 물리가 아니라 **구적 앨리어싱**일 가능성이 높다 (두 경로가 P₂ 를 다른
방식으로 적분한다). 그러나 **확정하지 않는다**. P4 게이트가 이것을 분리한다:
각 해상도를 올려 차가 사라지면 앨리어싱, 남으면 물리 (E→I 되먹임).
★ 이 판별 전에는 "편광이 감쇠율을 바꾼다/안 바꾼다" 어느 쪽도 주장하지 않는다.

## D7 ★★ **닫혔다** — 부스트 하 스크린 회전 ψ = 0 (85차, P9a)

83차에는 "부스트 (Q7b) 하에서 ψ 의 추가 회전 — 광행차가 스크린을 돌린다" 를
**예상**으로 적고 미유도로 남겼다.  그 때문에 `polstate.collide(v_b != 0)` 이
`NotImplementedError` 로 거절하고 있었다.  이제 쟀다 — **예상은 기각된다.**

스크린 대표원을 부스트한 뒤 게이지 복원한 사상
```
W′_a = (ΛW)_a − ((ΛW)⁰/E′) p′_a ,     S : 스크린(ê) → 스크린(ê′)
```
을 산란면 적응 기저 (m₁ ∝ P_⊥[v], m₂ = ê × m₁) 에서 SVD 한 결과 —
무작위 400 조합, |v| ≤ 0.6:

| 항목 | 실측 |
|---|---|
| \|배율 − 1\| | 4.44e−16 |
| 이방도 | 6.66e−16 |
| **\|ψ\|** | **6.67e−16** |
| 왕복 (정지계 왕복) 항등 | 7.77e−16 |
| 제약 이탈 (W′·ê′) | 1.66e−15 |
| 무편광 → 무편광 | 2.78e−16 |
| tr J 보존 | 1.78e−15 |

⇒ **부스트는 추가 회전을 만들지 않는다.**  D3 (수송 홀로노미) 과 같은 구조다:
배율 1 의 등거리이고, 산란면 방향을 산란면 방향으로 보낸다.  광행차는 ê 를
돌리지만 스크린 **안에서의** 회전은 만들지 않는다.

**왜 배율이 1 인가** (해석): Λ 는 계량을 보존하고, 게이지 복원에서 빼는 것은
**널** 벡터 p′ 의 배수다.  |W′ − αp′|² = |W′|² − 2α(W′·p′) + α²(p′·p′) 에서
마지막 항은 p′ 이 널이라 0, 가운데 항은 W·p = 0 의 부스트 불변성으로 0.
⇒ 노름이 정확히 보존된다.  "배율이 1/D 일 것" 이라는 순진한 예상은 틀렸다 —
도플러 D 는 **진폭** (E′ = D E) 에 붙지 스크린 벡터에 붙지 않는다.

**귀결 (P9b 규격)**: 편광 × 부스트는 새 기계가 필요 없다.
```
J′_ab(ê′) = S_a^c S_b^d J_cd(ê) ,      S = Π(ê′) Λ Π(ê) | 스크린
```
이고 기저-없는 캐리어에서는 자동이다.  `polstate.collide(v_b)` 의
`NotImplementedError` 는 제거할 수 있고, 구현은
**정지계로 부스트 → rank-9 3항 → 되부스트** 세 줄이다.
검증: `audit/p9_boost_screen.py`.
