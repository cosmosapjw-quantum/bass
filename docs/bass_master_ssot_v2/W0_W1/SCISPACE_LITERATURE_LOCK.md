# SciSpace literature lock — W0/W1 methodology

**Search question:** What peer-reviewed methods and software papers support
using Wolfram Language with xAct/xTensor and xCoba for exact tensor
derivations, orthonormal-frame component calculations, and reproducible
symbolic verification of homogeneous Bianchi cosmological background
equations?

## Admitted methodological references

1. I. Agullo, J. Olmedo and V. Sreenath, “xAct Implementation of the
   Theory of Cosmological Perturbation in Bianchi I Spacetimes,”
   *Mathematics* **8** (2020) 290, DOI `10.3390/MATH8020290`.

   Admitted use: evidence that an xAct-based pipeline can organize tensor
   calculations on an anisotropic cosmological background. It does not
   authorize this project’s nonperturbative all-Bianchi equations.

2. D. Brizuela, J. M. Martín-García and G. A. Mena Marugán,
   “xPert: Computer algebra for metric perturbation theory,”
   arXiv:`0807.0824`.

   Admitted use: xAct index canonicalization and programmatic tensor
   manipulation methodology. Perturbation formulas are outside this stage.

3. M. Hohmann, “xPPN: An implementation of the parametrized
   post-Newtonian formalism using xAct for Mathematica,” *European Physical
   Journal C*, DOI `10.1140/EPJC/S10052-021-09183-9`.

   Admitted use: evidence for separating abstract decomposition, formal rules
   and generated equations in an xAct package.

## Exclusions

These references are methodological support only. They do not determine the
BASS signs, screen conventions, eleven Bianchi branches, exceptional
`VI_{-1/9}` sector, polarized hierarchy, local/global tilt discrimination,
or numerical/scientific validation.
