# SYNC-MAP-01R1 dual audit

## Scope

This audit covers only the mapping of the fifteen BASS-owned formula families
in the refined federation proposal to their currently observable source
lineages. It does not prove formula equivalence, numerical parity, provider
compatibility, or scientific validity.

### Physics firewalls

- Bianchi algebra, Levi-Civita connection, spatial curvature, Einstein
  projections, and temporal structure evolution are separate stages.
- Global/electron-frame finite tilt is not an observer-only local boost.
- The cold electron-rest Thomson theorem is not promoted as a finite-tilt or
  production collision path.

  finite-L compiler or numerical solver.

  is composed on the current connection line and replayed.

The current map preserves the existing I/V/IX curvature witnesses as sibling
evidence, but it does not generalize those witnesses to all eleven Bianchi
families. The exceptional VI_-1/9 sector remains a dynamical sector of VI_h,
not a twelfth algebra type. No FLRW, finite-tilt, recombination, reionization,
or likelihood claim is changed by this stage.
