★★ **87차 반증 (이 표가 스스로 잡았다).**  처음엔 "class A 는 Codazzi 가
기계정밀" 이라고 적었다.  거짓이다 — 기계정밀인 것은 **Bianchi I 뿐**이고
(곡률항이 아예 없다), 곡률이 있는 class A 도 1e-5 수준의 잔차를 갖는다.
차이는 **크기가 아니라 수렴 차수**에 있다:

  · class A 곡률형 (II, VI_0, VII_0, VIII, IX) : 차수 ~3.6-3.9
    T4 (N-항의 l<=1 모멘트가 정확히 0) 가 저차 오차를 막아 고차 앨리어싱만 남는다.
  · class B (IV, V, VI_h, VII_h, III, VI*)     : 차수 ~2.3
    A-항이 l=1 에 **직접** 작용한다 — Q5b 가 등재한 mu-꺾임 축 (2.45) 과 같은 축.

그래서 합격 판정을 절대 임계가 아니라 **수렴 차수 >= 1.5** 로 둔다.
절대 임계를 쓰면 곡률형 전부가 해상도만 낮으면 탈락하고, 해상도를 올리면
통과한다 — 물리가 아니라 격자를 재는 게이트가 된다.
