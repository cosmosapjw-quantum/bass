# Decision log

## D-001 — Scope firewall

BASS v1.0 is homogeneous/background-only. High ell is angular resolution, not a
spatial perturbation hierarchy. Perturbation, likelihood, and real-data authority paths
remain locked out of scope.

## D-002 — Harness transplant method

Do not overlay the two generic harness ZIPs or the legacy automation kit. Build one
namespaced BASS harness from audited concepts because the upstream roots conflict and
their validators permit false-green placeholder states.

## D-003 — External repository role

Pin `bianchi_phase_r` at commit `539fcd6acc81dfd19d05951c2c5cbc3602eda077`
as a read-only external oracle pending owner confirmation. It has no production authority.

## D-004 — Toolchain deferral

Rust 1.94.1 bytes are authenticated, but installation and execution are deferred until
the canonical code declares its toolchain/MSRV and the user authorizes the verification
phase.

## D-005 — Static evidence execution snapshot

H0/H1 PASS logs use `bass.static_check_log/v2` and bind the exact governing snapshot both
before and after command execution. Past logs are never eligible for reissuance after a
governed-byte change.

## D-006 — Live-state immutable projections

Owner decision values, phase authorization bits, claim statuses, DAG/gate statuses, and
receipt pointers may evolve. Their definitions and all agent-readable semantics remain
H1/OD0-governed through immutable JSON projections; run-state guidance is machine-coded.

## D-007 — Location-bound bootstrap evidence

H0/H1 static evidence is deliberately bound to the current Work harness root, workspace
parent, and resolved Python runtime. A relocated copy must issue fresh evidence; it may
not reuse historical logs that could have executed against a different tree.

## D-008 — Authorization is not activity history

Live authorization bits state what may occur next. Solver execution, solver modification,
and external-oracle execution become cumulative historical facts only through dedicated,
hash-bound activity receipts and cannot be inferred from current permission state.
