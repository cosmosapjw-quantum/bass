## New process-level findings from the blocked-input incident

1. Same filename is not artifact identity.
2. A receipt without exact source/artifact binding is historical evidence, not executable authority.
3. A missing artifact must return `BLOCKED_INPUT_REQUIRED`, never a scientific FAIL or PASS.
4. Expected hashes, tolerances, goldens, and tests are immutable inputs to verification.
5. Absolute-path sidecars are non-portable metadata defects.
6. Generated caches can contaminate extraction-based manifests; verification must use fresh extraction or an explicit cache policy.
7. Artifact retention and attestation are necessary provenance controls, but neither proves scientific correctness.
