# BASS-8B.2B carrier-choice preflight package

This package records a bounded carrier decision and a corrective dependency
finding. It selects the generic-vector paired rest-to-normal physical-screen
bundle as the discrete reference carrier, while showing that the
**direction-dependent** collision-rate map must be bound before the paired left
invariant and full normalized projector can be closed.

Run:

```bash
python -m pytest -q
python source/exact_rate_multiplier_witness.py
python source/run_numerical_audit.py
```

The package is not production code, a continuum finite-tilt theorem, an
authority-row promotion, a VI0 classifier, or a solver/runtime implementation.
