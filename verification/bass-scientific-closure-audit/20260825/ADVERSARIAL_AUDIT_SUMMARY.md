# Adversarial scientific audit summary

## Best-supported interpretation

H2: BASS is a strong exploratory low-ell solver framework with several strong formula/discrete components, but major closure is required for broad solver, output, statistics and optimization claims.

## Load-bearing findings

1. The SSOT and eleven-family atlas are strong formula authorities, but explicitly exclude finite electron tilt, solver construction, numerical evolution and inference.
2. Fresh standalone reruns support 2B.1 and 2B.2. The currently materialized 2B.3 candidate passes its own earlier 51-entry/28-test surface, but is not the declared final 57-entry/53-test package.
3. The pinned `htt/bass` tilted projected collision path uses an axisymmetric boost-to-tower comparator; the generic-vector paired authority is not production-wired.
4. The angular Mueller path is I/Q/U; a four-Stokes I/Q/U/V headline needs an explicit V contract.
5. Eleven-family registry/background/backend contracts are real, but six families use residual-backed IC and publication readiness requires residual packs not replayed here.
6. Global tilt/local boost and deterministic/stochastic/boost splits are explicitly represented, but stochastic arrays, maps and anisotropic B outputs are not uniformly complete.
7. The inference wrapper is fail closed. Direct likelihood code is diagnostic-only; hard-coded tangency compatibility fields must not become readiness evidence.
8. Selected numerical lanes are strong, but an all-family cutoff/tolerance/TCA/tilt/E-B convergence matrix is still absent.
9. Optimization guards are conceptually honest, yet the generic-vector authority has no same-physics Rust lowering/benchmark.

## Verdicts

- Physics: strongly implemented with caveats at formula/reference level; partial end-to-end.
- Family coverage: broad but uneven.
- Observables/statistics: bounded harmonic diagnostics only; not statistics-ready.
- Numerical maturity: strong low-ell evidence in selected lanes; not globally publication-grade.
- Optimization: useful framework; generic-vector optimization premature.
- Overall: serious low-ell solver package with major closure required.

## Allowed headlines

Exact formula core under stated assumptions; eleven-family formula atlas and broad registry architecture; bounded discrete generic-vector reference results with package qualification; explicit output split and fail-closed gates.

## Disallowed headlines

Publication-grade eleven-family finite-tilt solver; production generic-vector Thomson runtime; complete maps/B-mode/stochastic outputs; Planck/data statistics-ready fitting; same-physics optimized generic-vector Rust backend.
