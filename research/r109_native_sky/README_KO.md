# 유한 tilt Bianchi 모드 아틀라스

네이티브 BASS 실행 파일 하나로 69회 계산했다. I, II, III, IV, V, VI₀, VIₕ, VI₋₁/₉, VII₀, VIIₕ, VIII, IX의 세 경로를 같은 격자와 전단 매개변수에서 비교한다. 각 계열의 초기 정규화된 구조상수·전단은 코드의 해당 초기조건에 따르므로, 숫자 간 차이를 관측된 계열 효과로 해석할 수 없다. 공통 기본 설정은 초기 전단 매개변수 0.18, Δη=0.35, 18 시간 스텝, Gauss–Legendre μ 10개와 φ 24개, ℓ≤4다. 외부 확률모형을 사용하지 않았다.

| 경로 | 물질 및 관측자 | 12개 기본 계열에서 최대 Hamiltonian / Codazzi 잔차 |
|---|---|---|
| active | 초기 에너지의 22%가 서로 반대인 두 먼지 흐름. 한 흐름의 초기 β=(0.16,−0.08,0.04). 충돌·관측자 속도 0. 광자와 먼지가 기하에 반응한다. | 2.04×10⁻⁵ / 1.47×10⁻⁶ |
| tracer | 별도 스칼라 복사 배경. 지정 전자 β=(0.14,−0.03,0.02), bare optical depth 0.22, 관측자 β=(0.1,0.035,−0.025). 산란한 편광장은 배경 소스를 바꾸지 않는다. | 1.25×10⁻⁴ / 3.17×10⁻⁴ (배경) |
| recoil | active와 같은 초기 두 먼지 흐름에서 첫 흐름이 전자 속도를 제공한다. bare depth 0.22, 움직이는 관측자는 tracer와 같다. 광자 momentum 교환을 첫 흐름에 반영한다. | 1.99×10⁻⁵ / 1.85×10⁻⁶ |

Recoil의 12개 기본 계열에서 충돌만으로 생긴 누적 광자+host 에너지 잔차의 절댓값은 전체 출력 시각에 걸쳐 최대 2.78×10⁻¹⁵(코드 고정 에너지 정규화), 스크린 최소 고유값은 0.0930이다. 이는 팽창·공간 발산이 들어가는 우주 전체의 에너지 보존 오차와 다른 진단량이다. VI₋₁/₉에서 Δη=0.8, 48스텝까지 연장한 경우 host의 단위질량 공간 운동량 p/(mc)=γβ는 (0.16276,−0.08138,0.04069)에서 (0.01748,−0.01182,0.00565)로 바뀌었다. 이 전후 차에는 광선과의 산란 및 측지선 진화가 함께 들어 있다.

기본 VI₋₁/₉에서 18→36→72스텝일 때 E의 상대 L² 변화는 0.00179→0.000908, B는 0.00300→0.00120이다. 같은 기본 설정에서 각도격자 (10,24)→(16,40)의 B 변화는 3.45×10⁻⁷이었다. 더 긴 Δη=0.8 계산에서는 48→96스텝 B 변화가 8.67×10⁻⁴, (14,36)→(20,52) 각도 변화가 1.57×10⁻⁵다. 이 연속 변화량은 연속체 해에 대한 보증 상한이 아니다. 두 계열에서 관측자·먼지·기하 초기값을 맞추고 τ=0, 0.11, 0.22도 비교했다. 위 기본 active와 recoil은 관측자까지 다르므로 τ 효과만 비교할 때는 ATLAS.json의 `matched_optical_depth`를 사용한다.

정지한 FLRW에서 최대 |aℓm|은 2.66×10⁻¹⁴, 움직이는 FLRW에서 정확한 흑체 도플러 온도쌍극자와 성분 차이는 8.19×10⁻¹⁶이다. 모든 1,725개 부호 있는 m에서 복소 T/E/B와 6종 곱 aᵡℓₘaʸ*ℓₘ를 재구성했다. 실지도 조건과 mode product 재계산 최대 오차는 0, Cℓ 재계산 차는 6.94×10⁻¹⁸이다. 모드당 3×3 행렬의 PSD와 rank≤1을 검산했다. T는 I¹ᐟ⁴를 그 각평균으로 나눈 값의 편차, Q/U는 bolometric Stokes를 4〈I〉로 나눈 값이다. 온도·편광 단위는 무차원이다. 각 시나리오의 결정론적 하늘과 수치 정밀도를 제공하며, 실데이터 likelihood나 primordial 공분산을 계산하지 않는다.

[ATLAS.json](ATLAS.json)에는 모든 실행 인자·파일 SHA-256·진단·Cℓ·수렴 비교가 있다. [ATLAS_MODES.tar.gz](ATLAS_MODES.tar.gz)는 원래의 modes.tsv, cl.tsv, diagnostics.tsv, run.txt 전체를 276개 파일로 수록한다. [run_atlas.py](run_atlas.py)는 Python 3.11+와 NumPy로 각각의 새 출력 디렉터리에서 실행한다. argv에는 실행한 절대 경로가 보존되므로 경로가 다른 재실행에서는 수치 TSV의 해시를 비교한다. 독립 분석에서는 archive를 압축 해제하기 전에 표본별 상이한 m 및 열 이름·정규화·좌표계를 확인한다.

```bash
cargo build --offline --release --manifest-path _rustcore/Cargo.toml --example homogeneous_sky
python research/r109_native_sky/run_atlas.py --with-recoil \
  --binary _rustcore/target/release/examples/homogeneous_sky \
  --raw "$HOME/Downloads/htt_r109_native_validation/replay_01"
```

이 결과의 release 실행 파일 SHA-256은 `2f6876ecb8b03c96b2c3387d3975648983e18912c3833f20322acf6498fe22ec`이다. 원 실행의 전체 파일은 `~/Downloads/htt_r109_native_validation/canonical.OIMrmB/atlas_public/`에 있다.

이번 배포는 정준 REC/REI 의존성과 최종 Codazzi 부호를 포함한 단일 바이너리로 69개 입력 모두를 재실행했다. 능동 경로에는 Raychaudhuri를 명시했다. 각 진단의 부호는 (Dⱼσʲᵢ+κqᵢ)/H²다. 이전 원 실행과 44개 모드 표와 44개 Cℓ 표가 바이트 단위로 같았고, 전체 69개 모드 표에서 수치 차이는 최대 3.23×10⁻¹⁵이다. 종전과 새 Codazzi 부호 성분의 합은 전체 시각에 걸쳐 최대 8.47×10⁻¹⁶이었다. 압축본 SHA-256은 `bc04eec2fa7a3887d228dfe886ea8c46c08bc8ef59d0033f71ed6a30f64e9844`다. 동일 바이너리의 독립 4개 회전 검산은 [실행 영수증](LIE_ROTATIONS.json)에 있다.
