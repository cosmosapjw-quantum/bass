## 2. 컨벤션 및 단위

서명 (-,+,+,+). n은 photon propagation 방향이며 observer sky -n이 아니다. 모든 I,Q,U,V 및 harmonic coefficient는 동일한 bolometric-intensity 단위다. 온도 또는 점유수로의 변환은 하지 않는다. 광학깊이는 chi=int n_e* sigma_T c dt_e >=0이며 무차원이다. Cold-electron Thomson, recoil-free 조건 아래 고정 event/frame의 angular kernel을 다룬다. 스펙트럼 provenance로 Thomson domain을 인증한 것은 아니다.

P8의 실제 float matrix를 J_code=S+A로 읽고 Hermitian coherency를 J_phys=S+iA로 해석한다. I=J_tt+J_pp, Q=J_tt-J_pp, U=J_tp+J_pt, V=J_pt-J_tp. 물리적 positivity는 두 차원 screen restriction에 적용한다. 3차원 행렬은 propagation 방향의 영 고유값을 갖는다.

정준 scalar real basis Z_lm은 Condon-Shortley complex basis의 BASS 실수 변환이다. U_1 순서는 (y,z,x), U_2는 m=(-2,-1,0,1,2)다. spin basis는

_sY_lm=(-1)^s sqrt((2l+1)/(4pi)) d^l_(m,-s)(theta) exp(i m phi)

의 같은 실수 기저 변환으로 정의한다. 이번 dictionary에서는

Q+iU = sum (E_lm+i B_lm) _2Z_lm.

같은 propagation 방향과 screen에서 외부 convention이 앞에 minus를 놓으면 E_ext=-E, B_ext=-B다. Observer-sky antipodal map은 별도이며 구현하지 않았다. Theta/phi frame의 pole singularity는 GL node가 pole을 제외하므로 현재 quadrature에 걸리지 않는다. 일반 masked/patchwise sphere는 별도 검증 대상이다.

## 3. source dictionary의 직접 유도

P=delta-nn, M=int J_code dOmega라 하자. J_S=(I/2)P+L, J_A=-(V/2)epsilon.n 이므로

tr M = sqrt(4pi) I00,

M_STF = -sqrt(2pi/15) sum_m (I2m-sqrt(6)E2m) U2m,

M_[ab] = -(1/2)epsilon_abk d_k,
d = sqrt(4pi/3)(V11,V1-1,V10).

근거는 int n_a n_b=(4pi/3)delta_ab와 int n_a n_b n_c n_d=(4pi/15)(delta_ab delta_cd+delta_ac delta_bd+delta_ad delta_bc)다. Frobenius-normalized STF U에 대해 scalar mode는 U:nn=Z2m/sqrt(15/(8pi))이고, unit E2 carrier는

J_E2 = sqrt(5/(16pi)) [P U P + (n.U.n)P/2].

그 적분은 sqrt(4pi/5) U다. Unit I2의 적분은 -sqrt(2pi/15) U다. 동일한 회전군 표현의 다섯 성분에 적용되며 모든 m은 독립 수치 대조했다. B와 다른 angular orders는 continuum scattering gain에 기여하지 않는다. Wolfram에서 m=0 tensor integrals의 residual은 두 경우 모두 3x3 영행렬이다.

이 14->9 map은 역변환이 아니다. I00 1개, I2 5개, E2 5개, V1 3개 중 gain이 보존하는 정보는 9차원이다. 각 m에서 I2m=sqrt(6)E2m인 다섯 조합은 M=0이어도 radiation state가 0이 아니다. Source extractor와 full-state representation을 구분한다.

## 4. projected collision generator

각 m에 대해 K2=[[1/10,-sqrt(6)/10],[-sqrt(6)/10,3/5]]이며 d(I2,E2)/dchi=(K2-Id)(I2,E2)다. gain eigenvalues는 {7/10,0}, collision-generator eigenvalues는 {-3/10,-1}다. Pi=I2-sqrt(6)E2는 exp(-3chi/10), complementary combination sqrt(6)I2+E2는 exp(-chi)로 감쇠한다.

I00는 보존되고, V1은 exp(-chi/2), B 및 나머지 source-null angular modes는 exp(-chi)로 감쇠한다. 이 결과는 정지 전자 collision-only 문제의 해이지 Bianchi Liouville 수송까지 포함한 닫힌 저차 ODE가 아니다.

처음 E2=0이면 I2/I2_initial=(6exp(-chi)+exp(-3chi/10))/7, E2/I2_initial=-sqrt(6)(exp(-3chi/10)-exp(-chi))/7. 첫 식은 기존 P8 결과를 재사용한다.

## 5. 초기 tail과 source-memory의 의미

새로 직접 확인한 Bianchi-I prescribed-field 검증: 초기 I40=1의 signed carrier는 M=0이지만 H=0.3/T*, sigma=diag(-0.2,-0.2,0.4)/T* 아래

Mdot = int [-(4H+n.sigma.n)J + tensor_rate(J)] dOmega

가 0이 아니다. 기존 Q moving measure의 미분 3n.sigma.n과 brightness rate -4(H+n.sigma.n)을 합친 식이다. 계산된 대각성분은 (0.04051323087784222, 0.04051323087784230, -0.08102646175568057)/T*, Frobenius norm=0.09923674348227812/T*다. 독립 moment 예측 Mdot_STF=-sigma_cd J4_abcd/2와의 최대 차이는 1.85e-15이다.

Signed basis를 물리 분포로 주장하지 않는다. 예를 들어 I=2와 I=2+0.1 Z40인 두 양의 무편광 상태에 같은 입력장을 적용하면 동일한 초기 M과 위 차이의 0.1배인 Mdot 차이를 갖는다. 따라서 rank-9 gain만으로 수송의 상태를 대체하지 않는다. 후속 KM-1/KM-3에는 full initial gain-null distribution과 고차 tail의 전달 항을 보존한다.

추가 finite-tail fixture에서 ell<=2로 carrier를 복원하면 L2 오차 0.12103718436910192가 남는데 scattering source 차이는 9.60e-17이다. Source agreement가 full radiation reconstruction accuracy를 인증하지 않는 구체적 예다. 무한 tail에 대한 일반 오차상계는 유도하지 않았다.

## 6. 실행과 검증

현재 실행: Python 3.13.5, NumPy 2.3.5, SciPy 1.17.0. 명령은 `python -m pytest tests/test_dictionary.py -q` 및 `python verify_dl2.py`다. 원 kernel은 importlib로 바이트 일치 vendor에서 직접 실행했다. 새 adapter가 P8의 eigenvalues를 재정의해 오라클을 대체하지 않는다.

세 GL x periodic grid (8,16),(12,24),(20,40), ell<=4의 92개 I/E/B/V basis마다 roundtrip, M, collision을 검사했다. 총 276개 basis 행과 네 optical depths (1e-8,0.1,1,8)의 12개 양의 혼합장 행이다. 허용오차는 실행 전 2e-11로 고정했다.

최대 roundtrip error=1.0294e-14; source error=1.9318e-14; basis collision error=1.0547e-15; mixed collision error=2.4425e-15. 모든 혼합장은 2D screen에서 양의 coherency를 유지하고 screen leak/monopole residual gate를 통과했다. 11개 pytest item 통과. Scalar harmonics는 SciPy spherical harmonics와 최대 4.78e-16, spin-2 Gram은 최대 6.72e-15다. 이 수치는 roundoff floor에 가까우므로 해상도 수렴차수로 해석하지 않는다.

Legacy screen에서 얻은 Q+iU는 z=cos(psi)+i sin(psi)를 이용해 z^2(Q+iU)_legacy로 변환하면 공통 screen과 최대 9.06e-16 차이로 일치한다. 변환을 생략한 차이는 약0.1644로 해상도 증가만으로 없어지지 않는다. E 부호반전, E source 삭제, 초기 null-state 삭제, high-tail streaming 삭제, screen phase 누락의 다섯 대조군을 검출했다.

최초 테스트 구현은 3D Hermitian 행렬의 strict-positive eigenvalues를 요구해 4개가 실패했다. 원인은 transverse coherency의 정확한 longitudinal null eigenvector다. 검증 대상을 2D screen으로 바로잡고 nullness를 별도로 검사했다. 물리 연산자나 허용오차는 바꾸지 않았다. 원 실패 로그와 수정 사유를 보존했다.

## 7. discrete measure와 남은 범위

위 source 식은 full-sphere continuum dictionary다. Listed GL grids는 검증한 band-limited fixture에 충분하다. Deformed Q grid, mask, undersampled sky에서 같은 continuum tensor identities가 이산적으로 정확하다고 가정하지 않는다. 그런 경우 raw M_h=sum w_h J_h가 기준이며 discrete Gram/source map과 aliasing 오차를 따로 검증해야 한다. 이 adapter가 그 모든 격자를 지원한다고 승격하지 않는다.

Native subagent 및 독립 모델 심사는 NOT_RUN이다. CAS 검산과 다른 수학적 표현의 비교는 독립 모델 심사로 세지 않는다. 최신 Rust ABI, Hubble clock/tilted electron wiring, finite-frequency collision, Einstein feedback, 3+1 fluctuation 및 production observables는 그대로 미완료다.
