## 3. 공통 수송식: 무엇을 비교해야 하는가

metric signature (-,+,+,+), 전파 방향 n, 시간 단위의 H와 sigma를 사용한다. curvature N=A=0, tetrad rotation R=0이며 t는 normal proper time이다. Q의 시간은 tau_H로 따로 표기한다.

에너지 각밀도 G의 물리적 정규화를 선택하면

    rho_gamma = integral G dOmega,
    energy_flux_a = c integral G n_a dOmega,
    pi_ab = integral G n_<a n_b> dOmega.

코드의 J_1은 위 energy_flux/c에 대응하는 moment convention이다. 이번 무차원 fixture에서는 모든 moment에 같은 고정 에너지 scale을 썼으며, SI 소스 normalization을 새로 맞추거나 rho를 사후 재정규화하지 않았다.

s(n)=sigma_ab n^a n^b, V^a=-sigma^a_b n^b+s n^a라 두면 정확한 characteristic은

    d ln p / dt = -(H+s),
    dn^a/dt = V^a.

운동량 적분의 경계항 p^4 f -> 0 at 0,infinity를 가정한 bolometric 수송식은

    partial_t G + V dot grad_S2 G = -4(H+s)G.

이는 sigma에 대한 일차근사가 아니다. 주어진 geometry 위의 선형 kinetic operator이며, Einstein feedback까지 선형이라는 뜻도 아니다.

### 3.1 Q 공변격자에서 빠뜨리면 안 되는 측도

Q는 p=M(t)q, mu=|M qhat|, Ghat=mu^4 integral f q^3 dq를 사용한다.

    w_phys = w_com |det M|/mu^3,
    Mdot = -(H I + sigma) M.

따라서

    d ln mu/dt=-(H+s),
    d ln w_phys/dt=3s,
    d ln Ghat/dt=-4(H+s),
    d ln(w_phys Ghat)/dt=-4H-s.

일반적으로 시간 의존 moment map M_ang(t)에 대해서

    Jdot = (M_ang_dot + M_ang L_direct) F

이다. `M_ang L_direct`만으로 H/J RHS를 비교하면 좌표/측도 변화가 빠진다. 고정 physical-direction Eulerian 표현에서는 동일 항이 angular divergence `div_S2 V=3s`로 나타난다. 두 표현은 같은 항의 위치만 다르다.

### 3.2 massless H/J hierarchy의 정확한 축약

질량0이면 velocity-weight index i가 사라져 J_l^(i)=J_l이다. 원 source의 signs=(+1,-1,-1)을 적용하면

    Jdot_<L> = -4H J_<L>
      - [5l/(2l+3)] sigma^b_<a_l J_(L-1)>b
      + (l-1) sigma^bc J_bcL
      - [l(l-1)(l+2)/(4l^2-1)] sigma_<a_l a_(l-1) J_(L-2)>.

특히

    rhodot = -4H rho - sigma:pi,
    J1dot_a = -4H J1_a - sigma_a^b J1_b,
    pidot_ab = -4H pi_ab - (10/7) sigma^c_<a pi_b>c
               + sigma^cd J_abcd - (8/15)rho sigma_ab.

이 식은 l=4를 0으로 닫지 않는다. 순간 RHS 검사에서는 필요한 이웃 moment를 direct angular quadrature에서 모두 공급했다. 따라서 아래 오차는 임의 l_max ODE 진화의 truncation error가 아니다.

## 4. 결정적 발견: scalar collision과 polarized collision의 동일성 경계

electron-rest frame에서 projector P(n)=I-n n^T, M_J=integral J(n)dOmega라 두면 기존 P8 gain은

    (K_pol J)(n) = (3/(8pi)) P(n) M_J P(n).

M_J 위의 induced operator는 symmetric sector에서

    Kbar(M)=0.7 M+0.1 tr(M)I,

antisymmetric sector에서 0.5 M이다. trace/STF/antisymmetric 고유값은 1,0.7,0.5이며 전체 angular operator의 gain rank는 9다. 이번 PSD/물리 fixture는 real-symmetric linear-polarization sector를 시험했다. arbitrary circular-polarization implementation 전체를 검증한 것은 아니다.

### 4.1 초기 unpolarized quadrupole의 정확한 유한 광학깊이 해

I_i(n)=1+A P2(mu), J_i=I_i P/2, |A|<1, chi=integral nu_e dt_e >=0를 사용한다. 다른 source/수송이 없는 정지 전자 충돌 문제다.

초기 M_J의 STF 부분은

    M_quad = (2pi A/15) diag(1,1,-2).

따라서 gain의 intensity quadrupole은 A P2/10이다. 초기 intensity RHS는 scalar Thomson kernel과 같지만, finite chi의 두 해는

    a2_scalar(chi)/A = exp(-9chi/10),
    a2_polarized(chi)/A = (6/7)exp(-chi)+(1/7)exp(-3chi/10)

로 다르다. 차이는

    (a2_polarized-a2_scalar)/A
       = (3/100)chi^2-(11/500)chi^3+O(chi^4).

Wolfram이 M_quad, trace gain, 두 해, 작은-chi 전개 및 초기 기울기 차0을 확인했다. 실제 `q/polarization.py::collide`도 full-polarized 해를 재현한다.

A=0.3, chi=1에서 a2_polarized=0.12634692290187308,
a2_scalar=0.12197089792217973이다. 이 차이는 각도 격자를 올려 없애야 할 수치오차가 아니다. 두 모델이 같은 최초 generator action을 주는 initial submanifold가 full polarized evolution에 대해 불변이 아니기 때문에 생긴다.

**D6 문서에 대한 국소 판정:** `docs/P-DERIVATION.md` D6의 finite-step intensity agreement를 보편적인 scalar/polarized equivalence로 해석할 수 없다. 본 smooth polynomial fixture에서는 aliasing 가설이 해석적으로 배제된다. 과거 D6 raw 전체를 새로 감사한 것은 아니며, 보존된 production 코드를 수정하지 않았다.

결과적으로 direct/multipole/memory 삼각검증은 같은 `physical_model_id`끼리만 해야 한다. scalar I-only H/J와 full I/E/B/V를 한 개의 equality oracle로 묶지 않는다.

## 5. Electron frame, normal clock 및 실제 dispatch

### 5.1 세 clock의 분리

- t: normal proper time.
- tau_H: Q expansion-normalized time, d tau_H=H dt.
- chi: 양의 Thomson optical depth. tau_H와 다른 변수다.

Q와 H를 비교할 때 `dJ/dtau_H=(1/H)dJ/dt`가 필요하다. 또한 Z=J/H^2 같은 normalization을 실제 진화 변수로 쓰면

    Z' = Jdot/H^3 - 2(Hdot/H^2)Z.

Q에서는 rho/pi를 실제 격자에서 읽고 H로 나누는 현재 source map을 먼저 유지한다. 이 항을 근거 없이 기존 소스의 bug로 판정하지 않는다. 새로운 normalized-moment state를 추가할 때 필요한 계약이다. 다른 G1B의 fixed-scale clock `ct/L_*`와 Q tau_H도 동일시하지 않는다.

### 5.2 Moving electrons: Doppler amplitude와 relative flux는 별개

n_e* proper density, beta_e=v_e/c, D=gamma_e(1-beta_e dot n)에서

    dchi/dt = n_e* sigma_T c D,
    dchi/dtau_H = n_e* sigma_T c D/H.

D^4 bolometric boost와 D^-2 angular measure가 이미 있어도 rate의 D가 대체되지는 않는다. beta=0.6에서 parallel/head-on/transverse ray factors는 0.5,2,1.25다.

현행 `docs/ELECTRON-COLLISION-RATE-CONTRACT.md`는 이 normal-rate contract를 명시하며 Q/Rust exponential wiring은 NOT PRODUCTION WIRED라고 선언한다. 실제 `PolQState.collide`도 boost 전후에 단일 `nu_dtau`를 P8 kernel에 넘긴다. 따라서 그 호출을 normal tau_H에서의 generic tilted exact timestep으로 승격하지 않는다. 이 결과는 이미 알려진 integration 경계를 확인한 것이며, 비틸트 fixture를 막지 않는다.

이 rate 문제만으로 bolometric Mode A가 수학적으로 닫히지 않는다는 결론은 나오지 않는다. Cold Thomson의 에너지 독립성은 유지되며, 필요한 것은 같은 frame과 normal clock의 올바른 generator다.

방향별 D를 scalar exponential의 chi에 단순 대입하는 것도 해법이 아니다. 방향별 loss와 angular gain이 보통 비가환이다. 고정 local coefficients에서

    Jdot = -D_loss J + U_v m,  m=M_v J

로 factorize하면

    m(t)=M_v exp[-D_loss(t-ti)]J_i
         + integral M_v exp[-D_loss(t-s)]U_v m(s) ds

라는 rank-9 moment-memory 문제를 구성할 수 있다. 이는 선형 block identity로 유도된 **후속 구성 후보**다. 실제 moving-electron BASS operator·screen·clock 전체에 연결하여 수치 검증한 결과는 아니다.

### 5.3 실제 호출 경로

`q/model.py::run`은 ModeB면 `modeb.evolve`, scalar fast path면 `fast.evolve`, 그 외 `integrate.integrate`로 간다. 읽은 이 함수는 `PolQState`를 자동 구성하지 않는다.

`q/polstate.py::evolve`는 별도의 entry이고 constant `nu, v_b`를 받아 `strang_step`을 호출한다. `collide_modeb`는 명시적 Python/Rust policy를 가진 별도 entry다. P8 수학/커널 존재와 model의 automatic polarized-history wiring은 다른 상태다.

Rust 대응: `characteristics.rs::char_rhs_split`, `hierarchy.rs::rhs_one`, `coeff_hier.rs::rhs_grid`, `pol_collide.rs::collide` 및 `collide_modeb`. 이번에는 앞의 Python 검증과 native 실행을 혼합하지 않았다. 구 source archive의 Rust 파일은 현재 native source의 byte identity를 주장하지 않는다.

## 6. 실제 수치 결과와 adversarial controls

허용오차는 실행 전 고정한 2e-11이다. RHS error norm은

이며 영점 근처 component-relative error가 아니다.

## 7. Background/fluctuation split에 추가된 구체적 계약

Q의 상태가 `ln G`이고 P8이 `J=G Jhat`로 amplitude/shape를 저장한다는 점 때문에, 향후 spatial projection은 저장 변수에 단순 평균을 적용해서는 안 된다. 동일 frame·screen 식별 및 spatial averaging measure를 고정한 뒤

    Jbar = P_space[ exp(ln G) Jhat ],
    delta J = J-Jbar

로 정의해야 한다. 일반적으로

    P_space[exp(ln G) Jhat] != exp(P_space ln G) P_space Jhat.

예를 들어 같은 부피의 두 셀 G_+=exp(a), G_-=exp(-a)는 mean G=cosh(a)이지만 exp(mean lnG)=1이다. 진폭 전개 없이 성립하는 차이다. 이 rule은 이번 code representation으로부터 도출되었으며 BF-1의 projector/gauge/constraint 문제 전체가 해결됐다는 뜻은 아니다. Signed delta J를0으로 clipping해서 양수화하는 것은 금지하고 total J의 물리 positivity를 감시해야 한다.

## 8. DAG 변경과 stop condition

기존 15개 node 구조는 유지했다.

- DL-1: 공통 operator/clock/measure/code-path 계약 **COMPLETE_SCOPED**. scalar Bianchi-I instantaneous 비교와 static electron-rest polarization까지만 검증됨.
- DL-2: READY_SCOPED. 다음은 same-physics carrier/moment dictionary다. P8 M_ab의 trace/STF/antisymmetric source를 intensity/PSTF·E/B/V convention에 연결한다. full polarized source를 scalar-only exponential과 비교하지 않는다.
- KM-2: NON_TILTED_KERNEL_CHECKED, 일반 tilted consumer와 production wiring은 OPEN. 기존 rank9와 snapshot 원문 재사용.
- KM-3: 아직 OPEN. time-ordered Bianchi polarized memory 구현/검증은 이번에 수행하지 않았다.
- DV-1: scalar and polarized triangles를 별도의 physical_model_id로 실행하도록 acceptance 수정.
- BF-1: physical carrier로 공간 평균 후 storage chart로 되돌리는 계약과 시간 의존 moment-map 항을 추가. 완료 승격 없음.

G1C/B3g/h/i 및 기존 생산 캠페인 예산은 그대로 둔다. 선택하지 않은 모든 원자/재이온화 공급자를 이번 local benchmark의 prerequisite로 추가하지 않는다. 전체 BASS 물리 완료율은 null, production ready는 false다.

최소 다음 실행: **DL-2의 polarized source dictionary**. 먼저 electron rest frame, N=A=0, fixed H clock에서 P8 collision의 M_ab와 canonical I_2/E_2 normalization을 연결하고, 이 보고서의 a2(chi) exact solution을 non-regression oracle로 사용한다. 기존 결과를 다시 만드는 캠페인이 아니라 빠진 moment adapter만 작성한다.
