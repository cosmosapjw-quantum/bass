# BF-1: 고정 gauge의 주기적 공간에서 비섭동적 background/fluctuation 사영

상태: `COMPLETE_SCOPED_FIXED_GAUGE_PHYSICAL_CARRIER_PROJECTION`.
현재 단위는 BF-1 하나이며 BF-2/BF-3/BF-4를 실행하지 않았다. 부모는 PR211, commit `1100fbb57230de2cac412c332f58ce8060210535`; 첨부 KM2C 원본 SHA-256은 `22a7115817d037b5c9cb1c793d0971b653215653b2bf8efb6b96d19d7f24f847`이다. 상위 조사·제한완료 집계는 6/15에서7/15로 바뀌며 전체 물리 완성률은 null이다. Production 코드, 물리 tolerance, 이전 과학 실행은 변경하지 않았다.

## 1. 정의와 실제 범위

서명은 (-,+,+,+), c는 유지한다. Synchronous slicing, lapse1, shift0 및 유한 고정 coordinate domain D=T^3를 선택한다. Bianchi-I reference coframe의 공간 translation으로 momentum fibre와 spatial tensor component를 식별한다. 이는 선택한 gauge의 trivialization이지, 임의 시공간의 path-independent parallel transport나 gauge-independent 평균이 아니다.

J는 bolometric physical P8 carrier이다. P8의 real storage S+A는 Hermitian physical coherency S+iA로 해석한다. 서로 다른 위치의 상태를 같은 normal observer, 같은 physical momentum magnitude/direction label, 같은 reference screen에 먼저 옮긴 후 평균한다. 이번의 구체적인 frame adapter는 SO(3) local-triad rotation과 정확히 짝지어진 physical rays에 한정한다. Generic boosted observers, 다른 angular grids의 interpolation, frequency remapping은 구현하지 않았다. Matched rays가 아니면 adapter는 오류를 낸다.

주요 projector는 Cartesian spatial axis 첫 번째를 유지하는 새 standalone NumPy module이다. 기존 DL2 `polarized_dictionary.py`의 harmonic convention과 carrier decoder를 원본 바이트로 재사용한다. All-m ell<=4 검사에서 angular discretization은8x16이며, 공간 검사는12/24/48개의 periodic x nodes로 수행한다. y,z에는 일정한 함수이므로 이들은 T^3 위의 유효한 시험함수다. 단위 테스트의 다른 grid는 별도 범위다. New IVP=0이다.

## 2. 두 공간 평균을 구별한다

공통 reference frame의 carrier를 F=T_x[J_x]라 쓰자. 양의 density w(t,x)로

  <F>_w = int_D w F d^3x / int_D w d^3x,
  (P_w F)(x)=<F>_w,
  bar F=P_w F, xi=(1-P_w)F

를 정의한다. 고정된 w에서 P_w는 선형이고 P_w^2=P_w, P_w xi=0, bar F+xi=F이다. 고정 w의 가중 L2 inner product에서는 상수 부분공간에 대한 orthogonal projection이다. 그러나 w=w[gamma]이면 (gamma,F)->P_w[gamma]F라는 결합 사상은 일반적으로 비선형이다. 진폭 전개는 하지 않는다.

Reference-volume/Haar 사영 P0는 주기적 coordinate volume에 대한 평균이다. 순수 homogeneous Bianchi-I에서 sqrt(det gamma)=a_x a_y a_z는 x에 무관하므로 정규화 후 P_volume=P0이며 Pdot=0이다. 팽창한다는 이유만으로 Pdot을 추가하지 않는다.

Physical-volume 사영 P_gamma는 w=sqrt(det gamma)를 쓴다. Inhomogeneous geometry라면 P_gamma와 P0는 다르다. 정확히

  <F>_gamma - <F>_0 = Cov_0(w,F)/<w>_0.

따라서 한 사영에서 평균0인 fluctuation을 다른 사영에서도 평균0이라고 사용할 수 없다. 이번 기준 state split은 P0로 고정하고, P_gamma는 명시적인 대안/진단 사영으로 제공한다. 양쪽의 identity를 자동 치환하지 않는다.

별도 manufactured volume fixture는

  gamma_ij = a_i(t)^2 exp[(2/3)b(t)cos x] delta_ij,
  w = (a_x a_y a_z) exp[b(t)cos x]

이다. b!=0이면 이것은 spatially inhomogeneous conformal deformation이지 homogeneous Bianchi-I solution이 아니다. 평균/미분 규칙을 시험하기 위한 positive prescribed metric이며 Einstein evolution을 주장하지 않는다.

## 3. 정확한 평균 진화 및 frame 미분

lambda=d_t log w, normalized density p=w/int w에 대해

  d_t p=p(lambda-<lambda>),
  d_t <F> = <d_t F> + <lambda F>-<lambda><F>.

즉 Pdot F는 measure-carrier covariance이다. Proper volume와 현재 synchronous zero-shift convention에서는 lambda=theta=-c K이다. Coordinate cell의 부피 변화와 양의 spatial normalization은 정의의 일부이며, angular weight를 보존오류에 맞추는 사후 재정규화와 다른 연산이다.

전체 비선형 진화 d_t F=N[F,...]가 주어질 경우

  d_t bar F = P N[F,...] + Pdot F,
  d_t xi = (1-P)N[F,...] - Pdot F.

따라서 P(d_t xi)=-Pdot xi이다. Pxi=0이라고 해서 P(d_t xi)=0을 별도로 강제하면 안 된다. 위 식은 정확한 분해이나 N[F]를 N[bar F]로 대체하는 닫힘을 제공하지는 않는다. 검사에 사용한 N(F)=-F^3는 nonlinear algebra fixture일 뿐 kinetic/Einstein equation이 아니다. F=1+0.8cos x에서 <N>=-1.96, N(<F>)=-1.0이며, 0.96의 차이를 버리지 않았다.

Local frame이 R(t,x)로 바뀌면 F=R J_local R^T이며

  d_t F=R d_t J_local R^T + [Omega,F],
  Omega=Rdot R^T.

여기서 local derivative는 fixed paired common-ray labels에서의 값이다. 임의의 local grid에서 시간에 따라 angular argument가 달라지는 항은 별도 remapping derivative를 포함해야 하며 이번 함수가 자동 추정하지 않는다. 코드의 frame-rate term과 spatial measure-rate term은 독립적인 것으로 유지한다.

## 4. 검증 가능한 비섭동적 측도 예

F(x)=1+eta cos x, w=exp[b(t)cos x]에서

  <F>_w=1+eta I_1(b)/I_0(b),
  d_t <F>_w=eta bdot[(I_0+I_2)/(2I_0)-(I_1/I_0)^2].

I_n은 modified Bessel function이다. eta=.7, b=.65, bdot=1.1/T_star에서 exact mean은1.2162739424163878, 변화율은0.3304952864813792/T_star이다. F의 local derivative는0이고 reference 평균은1로 일정하다. 따라서 이 변화율 전체가 measure term이다.

12/24/48 공간 node에서 mean 오차는6.71e-14/2.22e-16/0, rate 오차는1.225e-12/0/5.55e-17이다. 별도의4차 중심차분에서 h=.04/.02/.01/.005 T_star에 대한 rate 차이는1.012e-7/6.335e-9/3.961e-10/2.475e-11이다. 이것은 평균 미분의 검산이지 solver 시간수렴 결과가 아니다.

## 5. Positivity, 저장 변수와 두 angular lane

평균해야 하는 것은 J=exp(logG)Jhat이지 logG나 trace-normalized Jhat 각각이 아니다. 같은 부피의 두 셀에서 logG=+b,-b이고 shape=P_screen/2이면 물리적 평균 intensity는cosh b, 평균log를 지수화한 값은1이다. b=.8에서 차이는0.3374349463048447이다. 새 float64 복원 adapter는 overflow/underflow를 거절하며, production의 넓은 dynamic range를 위한 log-sum-exp 합산까지 구현하지 않았다.

각 위치의 Hermitian J가 같은 screen에서 positive semidefinite이고 w>0이면

  z^dagger bar J z=int p(z^dagger J z)>=0

이므로 평균도 PSD이다. Space metric gamma의 성분을 고정 coframe에서 양의 가중치로 평균하면 같은 논리로 SPD가 유지된다. 이 두 가지는 증명된 convexity 성질이다. Signed fluctuation xi는 별도 복사 유체가 아니므로 PSD일 필요가 없다. 시험에서 full carrier의 최저 screen eigenvalue는0.369662..., reference 평균은0.934935..., fluctuation은-0.664754...였다. Physical-volume fluctuation에는-0.870138...도 나온다. Clipping하면 정확한 재구성과 평균0 조건을 바꾼다.

동일 observer/directions/screen에 대해 x-independent angular linear map H를 쓰면

  H P_space = P_space H.

따라서 기존 direct carrier와 harmonic/PSTF lane의 공간 분해는 같은 물리 상태를 표현할 수 있다. 이 명제는 homogeneous streaming operator나 x-dependent boost/opacity까지 모두 가환한다는 주장이 아니다. 실제 검사에서 all I/E/B/V modes through ell4의552행을 생성했고 mixed-field harmonic commutator 최대는1.78e-15였다. Reference 배경 I40=.3을 그대로 보존했다. Physical-volume mean은 fixture에서 I40=.35561329948로 다르며 그 자체가 일관된 가중평균이다. 공간 평균이 background를 monopole로 만들지 않는다.

## 6. 평균 metric의 positivity는 Einstein constraint를 해결하지 않는다

K_ij=-(1/2c) d_t gamma_ij, Lambda=0를 채택한다. ADM constraints는

  H_ADM = R^(3)+K^2-K_ij K^ij -16piG epsilon/c^4=0,
  M_i = D_j(K^j_i-delta^j_i K)-8piG j_i/c^4=0

형태로 정의하고, 이번 구체 예에서는 j_i=0이다. Gamma=delta인 flat T^3의 한 초기 slice에서 xhat=x/L_star, period2pi를 쓰고

  K_ij = L_star^-1[-k0 delta_ij + a cos(xhat) diag(0,1,-1)],
  epsilon = c^4/(16piG L_star^2)[6k0^2-2a^2 cos(xhat)]

로 둔다. 압력0, normal-rest matter의 initial density로 해석할 수 있지만 후속 evolution은 풀지 않았다. Local Hamiltonian은 항등적으로0이고 momentum 역시0이다. K의 trace는 일정하므로 이 초기 slice의 normalized physical-volume measure는 reference measure와 같고 Pdot도0이다.

k0=.4, a=.3에서 source16piG epsilon L_star^2/c^4는0.78..0.96, 평균0.87로 양수다. 평균 metric은여전히delta이고 평균K=-.4delta/L_star이지만

  H_ADM[bar gamma,bar K,bar epsilon]=a^2/L_star^2=.09/L_star^2.

실제 local H residual은최대4.44e-16/L_star^2, local momentum은3.06e-15/L_star^2 이하였다. Nine fixtures(nx12/24/48, amplitude.1/.3/.6)에서 mean residual은a^2와6.59e-16 이내로 일치했다. 이 차이는

  <delta K_ij delta K^ij>=a^2/L_star^2

와 정확히 같다. 이 특정 예에서 variance를 포함하면 averaged constraint가 닫히지만, 임의 inhomogeneous gamma의 curvature/backreaction closure를 해결한 것은 아니다. 이는 한 정확한 반례이지 평균 우주론 전체에 대한 no-go 정리가 아니다. BF4의 constraint-preserving initial data 및 dynamics는 열린 의무로 유지한다.

## 8. 실행, 실패, 다음 한 단위

최종13개 고유 pytest가 통과했다. 과학 실행은552 basis,6 mixed,3 frame,3 measure,4 derivative 및9 constraint rows를 계산했다. New IVP0, historical campaign rerun0이다.

첫 과학 실행은 모든 row를 atomic save한 후, 마지막 homogeneous diagnostic에서 ndarray self.pdot와 method pdot의 이름 충돌로 실패했다. 회귀 테스트로 재현한 뒤 ndarray를weight_rate로 이름만 변경했다. 기존 행은 다시 계산하지 않고 --resume-saved로 읽어 마지막 진단과 acceptance만 완결했다. 원 실패/회귀실패 로그는 보존했다. 물리식이나 tolerance는 바꾸지 않았고 실패를 runtime blocker로 분류하지 않았다. JSON의 elapsed_seconds는 resumed finalization invocation만의 시간이므로 전체 캠페인 성능 수치가 아니다.

Native subagent와 독립 모델 심사는NOT_RUN이다. 외부 CAS는 local/mean constraints, projector identities, covariance와 log bias를 별도로 점검했으며 반환 warning도 그대로 저장한다.

BF1은 고정 gauge의 state representation/derivative contract를 닫았다. Parent kinetic/electron/EFE 코드를 호출하는 production integration은 수행하지 않았다. BF2의 실제 mean collision correlation, BF3의 spatial characteristic transport, BF4의 self-consistent gravity를 자동 실행하지 않는다. 다음 BF2는 같은 common-frame physical-carrier 사영 위에서 국소 electron-frame collision을 적용한 뒤 평균해야 하며, mean opacity/velocity를 먼저 넣는 대체와 구별해야 한다. 최종 원격 commit/backup은 외부 DELIVERY_FINAL.json의 실제 응답을 기준으로 확인한다.
