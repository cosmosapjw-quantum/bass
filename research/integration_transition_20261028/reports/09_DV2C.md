## 1. 물리적 범위와 coframe

서명 (-,+,+,+), normal proper time t, geodesic/nonrotating normal tetrad, 무질량 bolometric I/Q/U/V, normal frame에 정지한 cold Thomson 전자를 사용한다. c는 물리식에서 유지한다. 작은 전단·복사 진폭 전개는 없지만 기하학은 prescribed이고 Einstein 방정식/제약을 풀지 않았다.

길이 차원의 좌표 x,y,z에서

    ds²=-c²dt²+ax(t)²dx²+ay(t)²dy²+az(t)²(dz-n0 x dy)²

를 선택한다. n0의 단위는 1/length, ai는 양의 무차원 척도인자다. ω³=dz-n0 xdy이므로 dω³=-n0 ω¹∧ω²이고 고정 공간군의 [X1,X2]=n0 X3를 갖는다. 단위 tetrad의 구조계수는 n_structure,zz=n0 az/(ax ay). normal-time 곡률률을 N=c*n_structure로 쓰면

    Nzz=Nzz(0)*(az/az0)/[(ax/ax0)(ay/ay0)],
    Hi=dot ai/ai, H=(Hx+Hy+Hz)/3, sigma=diag(Hi-H),
    dot Nzz=(-H+2sigma_zz)Nzz.

이 관계는 Jacobi/coframe 적합성이지 Einstein matter closure가 아니다. H,sigma,N을 독립적으로 고정하는 임의의 시계열은 이 선택 metric과 일치하지 않을 수 있다.

코드에서는 u=t/T*, 좌표를 cT*로 나눈 값을 사용한다. 모든 rate는 물리 rate*T*이고 log ai=hi*u+di*u²/2. primary h=(.12,.45,.28), d=(.16,-.12,.08), ai(0)=1, Nzz(0)=.9, u=[0,.4]. ν=T*n_e*σ_T c=1.1+.2cos(2u), χ(u)=1.1u+.1sin(2u). 기존 API kappa(t)는 χ를 뜻하는 compatibility 이름이며 curvature k0와 같지 않다.

## 2. 방향, 에너지, screen, 각도 면적

s=n·sigma·n, v_sigma=-sigma n+s n이라 하면

    dot n=v_sigma+(N n)×n,
    dot log r=-(H+s),        r=E_gamma(t)/E_gamma(0),
    Ω_N=Nn-tr(N)n/2,
    dot E_screen=[v_sigma nᵀ-n v_sigmaᵀ+[Ω_N]×]E_screen.

E_screen은 3×2 직교 screen 기저이며 harmonic E mode가 아니다. tangent screen vector W에 작용하면 dot W=n(n·sigma·W)+Ω_N×W와 같다. 등방 H는 screen 방향을 돌리지 않는다. 곡률 intrinsic screen term을 빼지 않았다. 이 해석적 RHS는 P8를 호출하지 않고 구현했고, P8 rotation-coefficient 기반 screen_vector_rate와 따로 대조했다.

구면 발산을 계산하면 tracefree sigma에 대해 div_S²(v_sigma)=3s이고 symmetric class-A N의 curvature 방향장은 div_S²[(Nn)×n]=0이다. 따라서 Jcal=dΩ(t)/dΩ(0)는

    dot log Jcal=3s,
    Jcal*r³*V(t)/V(0)=1,     V=ax ay az

를 만족한다. 마지막 항등식은 Bianchi-I 선형 운동량 사상을 가정하지 않는다. N이 방향을 바꾸면서 r,Jcal에 간접 영향을 주지만 곡률의 구면발산이 0이라 부피 관계가 남는다. 이 class-A identity를 class B로 무조건 일반화하지 않는다.

독립적인 면적 검증에서는 초기의 두 단위 구면 접벡터 T1,T2를

    dot T=D_n v T,
    D_n v=-sigma+s I+2n(sigma n)ᵀ-[n]×N+[Nn]×

로 전파하고 Jcal_tangent=n·(T1×T2)를 계산했다. area ODE의 우변을 다시 적분하는 방식이 아니다. normal direction이나 screen을 사후 재정규화하지 않았고 raw quadrature weights w=w0 Jcal을 사용했다.

## 3. 독립 좌표 Hamiltonian oracle

위 metric에서 p=(Px/ax,(Py+n0 x Pz)/ay,Pz/az). normal-time null Hamiltonian은 H_null=c|p|다. 코드의 rescaled 좌표에서는 c가 T*와 함께 단위에 흡수된다. canonical Py,Pz는 Killing constants이며

    dx/du=px/(ax |p|), dy/du=py/(ay |p|),
    dz/du=k0 x dy/du+pz/(az |p|),
    dPx/du=-k0 Pz py/(ay |p|), dPy/du=dPz/du=0.

이를 독립 IVP로 적분했다. 이 경로는 tetrad direction RHS, P8, screen/memory 코드를 호출하지 않는다. explicit coordinate metric과 provider의 e,r가 맞는지 확인한 것이며 모든 coordinate/frame convention을 전역적으로 검증한 것은 아니다.

## 4. 같은 memory와 analytic harmonic 공급자 연결

parent SourceMemory와 VolterraHistory 원본은 변경하지 않았다. geometry protocol의

    mu=r, w=w0 Jcal, v=w0 Jcal r⁴

를 제공하면 J=r⁴ E X Eᵀ, M=∫JdΩ와

    dot X=-νX+(3ν/8π)r⁻⁴ Eᵀ M E

에서 얻은 Volterra kernel은

    K(t,s)[M]=(3ν(s)/8π)exp[-χ(t)+χ(s)]
       ∫dΩ0 Jcal(t)[r(t)/r(s)]⁴ Z(t,s)MZ(t,s)ᵀ,
    Z(t,s)=E(t)E(s)ᵀ

가 된다. 초기항은 full X0를 전달하며 gain-null 초기 편광을 버리지 않는다. 이것은 9변수 Markov closure가 아니다.

Direct 경로는 물리 carrier의

    dot J=-4(H+s)J+P8.tensor_rate(J)+ν[(3/8π)PMP-J]

를 별도 적분한다. Harmonic 경로는 부모 analytic shear generator와 instantaneous curvature generator를 더해 time-dependent Galerkin RHS를 구성한다. 각도 구적이나 direct source로 harmonic 행렬을 맞추지 않는다. L 밖의 항은 명시적으로 0이며 L4/6/8은 일반 exact closure가 아니다.

primary kernel의 opacity factor를 제거한 뒤 동일한 lag에서 비교해도 최대 차이가 .00334426293228518이었다. 이는 이 u-clock/representation에서 frozen lag-only kernel을 그대로 쓸 수 없음을 보여준다. 모든 가능한 변수변환에서 convolution이 불가능하다는 정리나 속도 측정은 아니다.
