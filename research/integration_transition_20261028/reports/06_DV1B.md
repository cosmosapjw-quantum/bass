## 1. 이번에 완료한 범위

DV1-A는 순간 harmonic RHS를 검증했다. DV1-B는 그 analytic generator를 시간적분하는 새 harmonic solver를 구현하고, 같은 기하학·초기 복사 분포에서 Cartesian P8 direct reference와 KM3 독립 Volterra 해를 비교했다. Harmonic IVP에는 angular quadrature, direct callback, Volterra callback 또는 source fitting이 들어가지 않는다. 새 코드는 기존 두 lane을 폐기하거나 production에 자동 연결하지 않는다.

검증 전에 주 구간 u=0..0.35, 별도의 긴 구간 진단 u=0..0.55, cutoff L=4/6/8, 물리 조건과 허용오차를 고정했다. 결과를 본 뒤 구간을 줄이거나 허용오차를 넓히지 않았다. 각도·시간·cutoff 오차를 따로 측정했다. 이것은 제한된 수치 benchmark이지 일반 Einstein–Boltzmann 계의 완성 판정이 아니다.

현재 턴에서 parent PR의 HEAD가 그대로이며 draft임을 읽었다. DV1 matching refs에는 DV1A만 있었다. 고정 ref에서 root와 research의 AGENTS.md는 각각404였다. 이전 두 ZIP의 SHA-256과 CRC를 확인한 뒤 필요한 vendor 원본만 가져왔다. Native subagent와 독립 모델 심사는 미실행이며, Python 실행은 실제로 성공했다.

## 2. 물리 규약과 단위

서명은 (−,+,+,+), n은 광자의 진행 방향이다. 관측 sky의 −n과 혼동하지 않는다. Bianchi I의 geodesic·비회전 normal tetrad를 사용한다. 복사는 무질량 bolometric이고, 전자는 normal frame에 정지한 prescribed cold bath이며 탄성 Thomson 산란을 사용한다. 물리적 충돌률은 nu_phys=n_e_star sigma_T c다.

수치 시간은 u=t/T_star이고 코드의 H, sigma, nu는 물리적 역시간 rate에 T_star를 곱한 값이다. Q의 d tau_H=H dt와 같은 clock으로 취급하지 않는다. Intensity, 산란 source M, reduced rho/q/pi는 공통 reference bolometric 정규화를 사용하며 normalization을 결과에 맞춰 재조정하지 않는다.

Canonical 실수 Z_lm과 Q+iU=sum(E_lm+i B_lm) spin+2 Z_lm 규약을 유지한다. P8의 실수 저장값 S+A는 Hermitian S+iA로 해석한다. Carrier를 비교하기 전에 같은 물리 방향·screen으로 옮긴다. Positivity clipping, density fitting 또는 raw 각도 가중치의 사후 재정규화는 사용하지 않는다.

기하학은 주어진 입력이다. EFE feedback, 모든 물질의 recoil/four-force, 주파수 재분배, 일반 tilt 또는 curved Bianchi를 검증한 것은 아니다.

## 3. Harmonic 시간적분

Spin0의 I,V와 spin2의 E+iB에 대해 DV1-A의 연산자를 그대로 재사용한다.

    dot f_s = -4H f_s -4 S(n) f_s + (grad S).D_s f_s/2,
    S(n)=sigma_ab n^a n^b,
    C_(l,lp)=[lp(lp+1)-l(l+1)-10]/4.

Wigner3j/Gaunt 행렬은 각격자에서 추정하지 않고 analytic 식으로 구성한다. 다섯 STF 전단 성분에 선형이므로 spin별 다섯 행렬을 미리 만들고 매 RHS에서 결합한다. E/B의 홀수 Delta-l 결합과 spin screen 연결항을 모두 유지한다.

P_L을 coefficient cutoff라고 하면 실제 유한계는

    dot a_L=P_L A(t) P_L a_L

이다. L 밖의 계수는 명시적으로0으로 둔다. 이 절단은 비섭동적 진폭 계산과 양립하지만 정확한 유한 closure는 아니다. 초기조건에 L보다 높은 mode가 있으면 조용히 버리지 않고 거절한다. L=4/6/8의 실수 상태 차원은92/188/316이다. 기존 L<=8 구현 벽은 바꾸지 않았다.

각 quadrupole m의 충돌은 full-polarized block

    K2=[[1/10,-sqrt(6)/10],[-sqrt(6)/10,3/5]],
    dot(I2m,E2m)_collision=nu(K2-Id)(I2m,E2m)

을 사용한다. I00은 충돌에서 보존되고, V1m의 감쇠율은nu/2, 나머지 gain-null mode의 감쇠율은nu다. Scalar-only 유한시간 해를 full-polarized oracle로 쓰지 않는다. DOP853 기본 rtol=2e-12, atol=2e-14이며, tighter1e-13/1e-15 실행은 시간 민감도 측정용이다.

Direct 경로는 pinned P8.tensor_rate를 호출하는 기존 KM1 Python reference다. Volterra는 unknown source를 독립적으로 푸는 KM3 알고리즘이다. 둘은 기하학을 의도적으로 공유하지만 harmonic RHS나 source history를 서로 공급하지 않는다. Production QState/Rust/Strang 실행이라는 주장은 하지 않는다.

## 4. Source 정확도와 전체 상태 정확도를 구별해야 하는 이유

Q_L=1−P_L, e_L=a_L−P_L f라 두면 정칙한 prescribed-field 선형 문제에서

    dot e_L=A_LL e_L−P_L A Q_L f,
    e_L(t)=−integral U_LL(t,s) P_L A(s) Q_L f(s) ds

가 된다. Retained observable O의 오차 O e_L는 tail의 되먹임을 가중 적분한 값인 반면, 전체 상태 오차에는 −Q_L f가 직접 포함된다. 따라서 source·density·flux가 전체 angular carrier보다 훨씬 정확할 수 있다. 여기서는 무한 tail이나 propagator norm을 enclosure하지 않았으므로 이 식을 계산된 전역 상계로 제시하지 않는다.

외부 Wolfram CAS에서는 retained low/intermediate와 omitted high의3×3 상수 블록을 시험했다. 초기 intermediate 상태에서 low mode의 full−cut 차이는 t^0,t^1,t^2에서0이고 t^3에서 b e f/6이 된다. 이는 tail이 나갔다 돌아오는 경로의 대수적 예시이며 BASS 전역 수렴률 정리는 아니다.

또한 spin0의 l=1<-l'=3 prefactor가 정확히0임을 확인했다. 이번 제한 조건에서는

    dot q=−(4H+nu)q−sigma.q,
    dot rho=−4H rho−sigma:pi

가 성립한다. 두 식을 새 단위시험으로 확인했다. q가 기계정밀로 일치하는 것은 일부 구조적으로 보호되기 때문이며 전체 고차 분포의 정확성을 인증하지 않는다. 전자 bath에 들어간 운동량은 별도의 동역학으로 진화하지 않았으므로 전체 four-force 보존 판정도 아니다.

## 5. 고정한 초기값 문제

주 noncommuting profile은

    H=.4+.05 sin(2u),
    sigma=diag(−.18,.03,.15)+sin(3u+.2)*[[0,.22,.09],[.22,0,−.12],[.09,−.12,0]],
    nu=1.2+.5 cos(3u)

다. 초기 계수는 I00=2 sqrt(4pi), I1,−1=.04, I20=.07, I40=.13, E22=.12, E3,−1=.025, B2,−1=−.03, V10=.04이며 나머지는0이다. 테스트된 모든 screen에서 초기와 진화한 혼합장은 양수였다. 이것을 일반 positivity theorem으로 승격하지 않는다.

Direct 각격자는10×20,16×32,24×48이다. Harmonic L=4/6/8은24×48 direct와 비교했다. Volterra32/64/128 time panels는16×32에서 수행했다. 주 삼각 비교는 같은16×32 물리 방향에서8개 시각의 carrier를 비교한다. Harmonic의 continuum source와 raw discrete moment 사이의 각도오차도 따로 기록했다.

사전 gate는 algebraic2e-11, 시간·fine각도source3e-9, primary harmonic/direct source1e-7, low ell<=4계수2e-5, full carrier2e-3, source-cutoff 개선비<.35다. 이는 이번 단위의 출력별 gate이며 과거 gate를 바꾼 것이 아니다. stress는 진단 전용이다.

## 8. 실행·실패·복구의 정확한 분류

최종11개 고유 pytest 항목이 통과했다. 독립 harmonic 실행, 정적 편광 충돌 해, 등방 무산란 redshift, 기존 순간 RHS와의 일치, source/carrier 변환, 잘못된 초기 cutoff와 시간 범위 거절, 초기 고차 tail, low moment balance 및 NumPy JSON 직렬화를 검사한다.

본 과학 검증은 원래10 harmonic IVP,7 direct IVP,6 geometry history,5 Volterra solve였다. 모든 수치 계산이 끝난 뒤 마지막 gate의 NumPy bool_를 JSON으로 저장하다 오류가 났다. 원시 checkpoint는 이미 저장되어 있었고 보존했다. 물리·수치 계산의 실패가 아니라 출력 구현 오류다.

엄격한 NumPy scalar encoder로 고치고, 저장되지 않은 E/B 대조군을 회복하기 위해 harmonic2회만 다시 실행했다. 총 harmonic debit은12이며 초기 상한18 안이다. 전체 direct/Volterra/cutoff 캠페인을 재실행하지 않았다. 마지막 schema의 L8 바깥 tail도 unknown/null로 교정했고 수정 전 코드·결과·로그를 남겼다. 물리 코드나 허용오차를 바꾼 복구가 아니다.

수정된 전체 validator는 syntax 검증했지만 출력 수리를 확인하려고 전체 캠페인을 다시 돌리지는 않았다. 실제 성공 명령은 repair_output.py, 최종11개 tests, verify_saved.py다. 테스트 내부 호출은 과학 캠페인 debit과 별개다. Native subagent/독립 모델 심사는 NOT_RUN이며 CAS를 독립 모델 심사로 세지 않는다.

초기 interactive container session 요청은 script 생성 전에 StreamingExecNotEnabledContainerError로 실패했다. 이어진 script-not-found 호출에서도 과학 계산은 없었다. 정상적인 동기 호출로 이어갔으며 Python unavailable 또는 RUNTIME_BLOCKED로 판정하지 않았다.

## 9. BASS 방법론과 다음 연구

이번 결과로 주어진 Bianchi-I 문제에서 full-polarized 유한시간 삼각 비교를 제한적으로 닫았다. Multipole 표현 자체는 진폭 섭동 전개가 아니며, 여기서 근사는 명시적인 finite-L 절단이다. Direct와 memory에도 각도·시간 이산화가 있다. 판정은 출력별로 해야 한다.

특히 background geometry에 공급하는 rho/q/pi와 충돌 M은 상세 각분포보다 빨리 수렴할 수 있다. 그렇더라도 향후 fluctuation과 backreaction이 고차 분포를 필요로 할 때 source-only 상태로 대체하면 안 된다. 공간 평균은 frame을 맞춘 physical carrier에 적용해야 한다는 기존 BF1 의무가 유지된다. 이번에 spatial splitting이나 Einstein feedback을 구현한 것은 아니다.

DV1 전체는 COMPLETE_SCOPED_BIANCHI_I_THREE_LANE_BENCHMARK로, 다음은 DV2의 untilted prescribed Bianchi-II 순간 곡률 generator 비교로 둔다. 모든 Bianchi 유형·tilted 전자·원자 공급자를 이 좁은 절편의 일괄 선행조건으로 추가하지 않는다. 동시에 그 범위들이 완료되었다고 주장하지 않는다. Source 조사 포함6/15이며 전체 물리 완성률null, production_ready=false다.

문헌에서는 Kamionkowski arXiv2105.02887의 hierarchy/integral 대조와 Challinor astro-ph/9911481의 일반 시공간 편광 다중극 문맥만 재확인했다. 후자의 정확한 제목은 Microwave background polarization in cosmological models다. 이번 턴에는 초록만 읽었으며 자체 계산 수치를 이 논문들의 결과로 귀속하지 않는다. 신규성 우선권도 주장하지 않는다.

## 10. 게시·백업 상태

이번 GitHub 도구 목록에는 read48개만 노출되었고 create/write/ref-update 동작 검색 결과가 없었다. Drive/Dropbox의 upload/create 검색에서도 파일 업로드 동작이 없었다. Plugin Management로 세 앱이 설치·활성 상태임은 확인했지만 이는 쓰기 도구가 있다는 뜻은 아니다. git 바이너리는 있고 gh는 없었다. 이 제한 때문에 원격 commit/PR/push와 Drive·Dropbox 이중백업은 이번에 미수행이다.

그 대신 검증된 로컬 ZIP, 전체 source/evidence, 상세 DAG, 인계서 및 새로운 research subtree만 추가하는 patch를 제공한다. Patch의 형식과 격리된 scratch 적용을 검사하더라도 실제 원격 게시와 같다고 보고하지 않는다. 다음 스레드는 현재 도구 능력을 다시 확인하고 이 원본을 먼저 백업·게시할 수 있다. 이전 실패는 다음 실행의 상태가 아니다.

재현은 이 디렉터리에서 단일 BLAS thread로 수행한다.

    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest tests -q
    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify_dv1b.py
    python verify_saved.py

새 과학 실행이 불필요하면 마지막 저장 증거 검사만 사용한다. 실제 다음 게시에서는 최신 HEAD/AGENTS와 source를 확인하고 expected-SHA non-force, create-only 백업 원칙을 유지한다. 기존 production과 owner branch는 건드리지 않았다.
