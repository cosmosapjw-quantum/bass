## 2. 연속 특성해와 유한 공간 절단은 같은 연산이 아니다

광선 초기 각도 label q, 현재 방향 n_q(t), 에너지 비 r_q(t), 전달된 normal screen E_q(t)로 J_q=r_q^4 E_q X_q E_q^T를 쓴다. v_q=c n_qx/(L_star a_x), ell_q(t)=∫v_qdt. 연속계에서

(∂t+v_q∂x)X_q=-ν(t,x)X_q+[3ν(t,x)/(8πr_q^4)]E_q^T M(t,x)E_q,
M=∫J_q dΩ_t.

현재 위치 x에 도달하는 과거 위치는 x_s=x-ell_q(t)+ell_q(s)이고, τ_q(t,s;x)=∫_s^tν(u,x_u)du이다. 따라서

X_q(t,x)=e^{-τ_q(t,0;x)}X_qi(x-ell_q(t))
 +∫_0^t e^{-τ_q(t,s;x)}[3ν(s,x_s)/(8πr_q(s)^4)]E_q(s)^TM(s,x_s)E_q(s)ds.

이 식은 공간적으로 비국소이다. 그러나 부모 BF3-A는 유한 Fourier-Galerkin P_K를 써서 opacity 곱을 P_K[ν f_K]로 계산한다. P_K e^{-τ}P_K를 그 유한차원 loss propagator와 동일시하면 안 된다. 정확한 반례로 ν=ν_*(1+εcos x), f=cos2x, K=2, streaming을 끈 loss 부분에서

P_2 e^{-νt}f - e^{-t P_2νP_2}f = (ν_*²ε²t²/8)cos2x+O(t³).

버린 공간 모드로 나갔다 돌아오는 항 PνQνP가 원인이다. Wolfram의 독립 Fourier 적분에서 위 계수와 경로별 loss PDE residual을 정확히 확인했다. 이것은 서로 다른 이산화를 구별하는 예이며, 연속 특성식의 오류나 일반적인 비가능성 주장이 아니다.

## 3. 같은 semidiscrete 문제의 정확한 source elimination

Fourier index k=-K,...,K를 numpy ordering으로 저장하고 V(t)_{kk'}=ν_{k-k'}(t)로 둔다. 모듈러 wrap/circular alias는 사용하지 않는다. 각 ray의 알려진 loss generator는

A_q(t)_{kk'}=-ik v_q(t)δ_kk' - V(t)_{kk'}.
Φ_q'=A_qΦ_q, Φ_q(0)=I, U_q(t,s)=Φ_q(t)Φ_q(s)^(-1).

이 IVP는 기하학과 opacity만 사용하며 radiation source나 초기 복사장에 의존하지 않는다. ν≥0이면 V는 Hermitian positive semidefinite이고 streaming은 anti-Hermitian이므로 연속 시간의 Galerkin loss propagator는 spatial L2에서 contractive이다. 역행렬 사용은 짧은 구간의 조건수를 별도 감시한다. 현재 main의 sampled 최대 조건수1.96445이며, 이를 장시간·stiff 조건으로 외삽하지 않는다.

Source 추출은

(L_t X)_k=Σ_q w_q(t)r_q(t)^4 E_q(t)X_kq E_q(t)^T.

Kernel은

K_kk'(t,s)[M_k']=(3/8π)Σ_q w_q(t)[r_q(t)/r_q(s)]^4
 [U_q(t,s)V(s)]_kk' Z_q(t,s)M_k'Z_q(t,s)^T,
Z_q(t,s)=E_q(t)E_q(s)^T.

b(t)=L_t U(t,0)X_i를 포함하여 M(t)=b(t)+∫_0^t K(t,s)M(s)ds를 얻는다. 균일 opacity에서는 U의 대각 phase exp[-ik(ell_q(t)-ell_q(s))]와 scalar attenuation으로 정확히 환원된다. 일반 opacity에서는 유한 cutoff에서 matrix U가 필요한 이유가 위 2절이다.

## 4. 독립 source marching

각 causal panel [a,b]에서 M(s)를 왼쪽/중간/오른쪽 값의 quadratic Lagrange polynomial로 근사한다. 중간과 오른쪽의 unknown9Nx source를 동시에 풀므로 main에서306×306 complex Fourier 선형계다. Conjugate symmetry 때문에 physical source에는153개의 real degrees of freedom이 있으며, solver는 generic complex matrix 계산을 사용한다.

각 kernel 적분은 GL4이고 GL6 감도도 비교했다. 과거 기여는 full ray/spatial2×2 carrier로 누적한다. 이는 source-only Markov closure도 angular state 삭제도 아니다. 전체 과거 panel을 다시 명시적으로 합산한 source와의 차이는3.55e-15이다. Same-grid direct source 주입은 없고, unit test에서 두 부모 radiation constructor와 radiation RHS를 예외로 대체해도 solver가 동작한다.

Source polynomial과 carrier에서 재구성한 source는 다른 dense-output 객체이다. Endpoint와 panel solve에서의 source 일치는 별도로 측정한다. Time causality는 완료된 panel에 대한 prefix 검사이며, 유한 Fourier 격자의 compact spatial support나 전역 positivity 정리를 주장하지 않는다.
