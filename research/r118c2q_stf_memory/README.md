# C2Q general STF massive memory
Exact linear constitutive relation with momentum-dependent initial STF anisotropy, angular and radial formulas and weighted Lyapunov derivation in THEORY.md. The initial J(q) shape is chosen as a smooth illustrative distribution, amplitudes in units of an arbitrary small perturbation parameter; initial S in STF component 1 is unity in these normalized units, or exactly zero for the source-only case. FD initial perturbation is a tangent to a positive deformed distribution; not a global finite-amplitude polynomial approximation. The reported 5D tensor angle is not a 3D eigenvector rotation. Six masses, two actual C2N histories, twelve all-feedback ODE runs plus zero-initial-shear and one independent Radau. Raw source hashes verified. Native Rust FermiMemory returns a^4 densities divided by present critical density and STF components in an orthonormal basis; provider is exported but not called by production geometry. Native/Python 774 grid rows, 18 direct centered finite-b tensor checks, rotation covariance, 48 general STF native screen collision comparisons in addition to previous C2N/C2O targeted tests. Background rebalanced as C2P, gas not recomputed for m.
