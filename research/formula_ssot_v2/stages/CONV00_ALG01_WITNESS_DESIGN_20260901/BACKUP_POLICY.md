# Per-stage durable backup policy

Every later Formula SSOT v2 DAG node must close with the same durable surfaces:

1. one immutable stage directory with exact upstream commit/tree;
2. headless `.wl` sources and a machine-readable Wolfram/xAct receipt;
3. PHYS-MATH followed by PHYS-MATH-CODE audit;
4. adversarial plot/data and a narrowed surviving claim;
5. source identity manifest and remote readback;
6. a non-force GitHub branch plus Draft PR;
7. a Dropbox mirror with returned paths/file IDs and readback.

GitHub owns code and exact committed evidence. Dropbox is a redundant backup, not scientific authority. Jira owns work state and dependency admission. A backup does not promote a formula, runtime, provider, or scientific claim.
