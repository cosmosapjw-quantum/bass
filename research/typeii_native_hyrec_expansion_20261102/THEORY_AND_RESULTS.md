## R2/C2 | Original external-Hubble atomic solver ownership and executed FLRW control

The original HYREC-2 `history.c::rec_build_history(HYREC_DATA*,int,double *hubble_array)` accepts external **positive** `H_i` values and internally evaluates them through `rec_interp1d(0,zmax/Nz,Hgrid,Nz,z)` on `z_i=8000i/Nz`. Its `hyrec_compute` sets `Hgrid[0]=-1`, selecting original `rec_HubbleRate` instead. Original atomic ODE code and rate tables are **unchanged**; this branch added only a standalone `native_external_h_driver.c` that directly calls the native documented source function. Source authority: CLASSIER-installed original `HyRec2020` original 18 C/header/atomic-table SHA-256 identities held by immutable parent `HYREC2_NATIVE_SOURCE_REPORT.json`; original BASS main unchanged.

An actual FLRW identity **control experiment** compiled the unchanged original five source C objects plus the isolated wrapper with GCC and ran three cases on the SAME pinned input: original source `rec_build_history(hubble=-1)` builtin, source `rec_HubbleRate` emitted as 2248-point uniform-z external table, then original `rec_build_history(hubble=HFLRW_table)`.
